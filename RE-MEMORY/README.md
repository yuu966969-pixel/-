# RE:MEMORY — 忘却の時間

PC専用・キーボード操作のみの3D SF RPGプロトタイプです。

## 起動方法
- `RE-MEMORY/index.html` をWebサーバー経由で開いてください。
- Three.js は jsDelivr CDN から読み込むため、初回起動時はインターネット接続が必要です。
- ローカル保存はブラウザの localStorage を使用します。

## 操作
| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| 視点 | ↑ / ↓ / ← / → |
| 調べる・観察・端末の研究画面を開く | E |
| 攻撃 | F |
| 穢れの捕獲 | C |
| ダッシュ | Shift |
| 局所時間操作 | Q |
| メニュー・設定 / データ管理 | Tab |
| メニュー内の選択移動 | ↑ / ↓ |
| 決定・開始・手動セーブ実行 | Enter |
| 戻る | Esc |

研究画面の選択も ↑ / ↓ と Enter で操作します。手動セーブは Tab で開くシステムメニュー内の「設定 / データ管理」から実行します。追加の番号キーや専用ショートカットは使いません。

マウス操作・タッチ操作は実装対象外です。

## 現在の実装
- Three.js による3D施設外周と荒廃した環境の仮ステージ
- 三人称プレイヤーとキーボード移動・視点操作
- 制御端末の調査とクロノス計画の導入ログ
- 穢れの仮モデル、接近行動、耐久値を使う戦闘試作
- 攻撃で活動を弱め、捕獲ビーコンで仮想収容する一連の捕獲試作
- 端末付近の研究コンソール、穢れ解析・時間制御強化・耐久修復
- 耐久値・穢れ観察データ・捕獲装置の状態表示
- 時間操作の試作（エネルギー消費・短時間の周辺演出）
- 20分ごとの自動保存（位置・エネルギー・侵食値・耐久・観察・捕獲進行）
- システムメニューの「設定 / データ管理」から手動セーブ
- 重要イベント時の即時保存と、2世代のバックアップ
