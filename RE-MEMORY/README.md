# RE:MEMORY — 忘却の時間

起動時にパソコン／スマートフォン・タブレットを選択できる3D SF RPGです。選択した端末に合わせて操作方法と画面レイアウトを切り替えます。現在は第1章を遊べる開発ビルドで、最終品質の完成版ではありません。

## 起動方法（PC・スマートフォン共通）

1. このリポジトリの `RE-MEMORY` フォルダを端末へダウンロードする。
2. PCの場合はWindowsのPowerShell、macOS/Linuxのターミナルでそのフォルダへ移動する。スマートフォンの場合は、HTTPサーバーを起動できるPCなどから配信するか、対応するローカルWebサーバーアプリを使用する。
3. HTTPサーバーを起動する。
   - Windows: `py -m http.server 8000`
   - macOS/Linux: `python3 -m http.server 8000`
4. PCではChrome/Edgeで `http://localhost:8000` を開く。スマートフォンでは同じネットワーク上の配信元PCのIPアドレスとポート（例：`http://192.168.x.x:8000`）をスマートフォンのブラウザで開く。
5. 最初の画面で「パソコン」または「スマートフォン・タブレット」を選び、「ゲーム開始」を押す。

※ `index.html` の直接起動（`file://`）は、データJSONとThree.jsの読み込み制限で動作しません。Three.js読み込みのためインターネット接続が必要です。

## 起動方法
- N.O.V.A.とNPCの会話は現在ローカルのルールベース応答です。入力内容は外部サーバーへ送信しません。
- 外部LLM接続は未実装です。APIキーをブラウザへ置く構成にはしていません。

- ローカル保存はブラウザの localStorage を使用します。

## 操作
起動時に選んだ端末に応じて操作UIが切り替わります。

**PC**
| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| 視点・メニュー移動 | 矢印キー |
| 調べる・会話・端末 | E |
| 通常攻撃 | F |
| 必殺技 | G（戦闘中のみ・武器ごとの必要攻撃回数で発動） |
| 穢れの捕獲 | C |
| ダッシュ | Shift |
| 時間操作 | Q |
| メニュー・設定 / データ管理 | Tab |
| 決定・開始・手動セーブ実行 | Enter |
| 戻る | Esc |

**スマートフォン・タブレット**
- 左下の方向パッド：移動
- 画面右側をスワイプ：視点変更
- 右下のボタン：調べる、時間操作、アクション、特殊操作、捕獲、ダッシュ、メニュー

スマートフォンではタッチ操作に対応します。

## 会話機能
- N.O.V.A.・商人・仲間との自由入力会話はローカルのゲーム内知識と人格ルールで応答します。
- 入力内容・会話履歴は外部APIへ送信しません。会話履歴はセーブデータへ保存します。
- 外部LLM連携は今後の開発対象です。

## 現在の実装範囲
- 空腹ゲージ、時間経過による空腹低下、空腹時の耐久・エネルギー低下。灰降りキノコ・穢れの肉片に加え、灰根イモ・残光ベリー・塩結晶草・水袋植物・焦げ穂コーン・月影ハーブ・鉄殻ナッツ・霧桃を採取可能。全10種類の食材と、焼きキノコ、穢れ肉の煮込み、焼き灰根イモ、残光ベリーの塩煮、水袋植物の滋養スープ、炭火焼き焦げ穂、月影ハーブ茶、鉄殻ナッツ粥、霧桃の塩漬けの9種類の料理を調理・食事できる。食材・空腹値・採取済み状態はセーブ対象。
- 3D探索、三人称移動、ローバーの乗降・運転、キーボード専用メニュー。
- 暗い終末世界のAPURF789、崩壊建築、漂う灰、制御端末、クロノス計画ログ、内部AI N.O.V.A.。
- 主人公の歩行サイクル、仲間のまばたき・会話中の口の動き・開口時だけ表示される歯の簡易表現。
- Web Audioによるオリジナルの低音環境音と戦闘・決戦時の効果音。システムメニューからON/OFF可能。
- 穢れ3種と大型個体「時喰らい」。観察・弱体化・捕獲・接近戦。時間制御を強化すると局所時間停止、さらに時間逆行による耐久・侵食の回復が解放される。
- 第1章の加入候補4人との遭遇・仲間登録。全30人のキャラクターカタログは章ごとの加入条件付きで管理し、会話・パーティー編成・育成に対応。編成メンバーの役割・レアリティ特性・レベルが攻撃力、防御力、時間操作時間に反映される。
- 3か所の記憶結晶、記憶の変換・貸借、返却期限と信頼への影響。仲間の記憶を奪うと本人の記憶からも消え、全て失うとその人物は世界から姿を消す。残響喰らいも主人公の記憶を奪う場合がある。
- 仮面の商人との敵対・中立・協力関係。記憶の扱いで関係が変化し、敵対時は記憶を要求・強奪するイベントが発生する。
- 基地拡張、6室の穢れ研究施設、段階に応じた3D研究区画。
- 武器100種の視覚スタイル・固有エフェクト・パッシブ情報、カテゴリ別3Dモデルと攻撃モーション。銃器は最大18m、槍は最大6.5mの攻撃距離を持つ。
- 防具6種、個別防御値・耐性・3D外観、武器ごとの最大3枠モジュール改造。
- APURF789探索マップ、時間異常区域3か所、区域解析報酬と移動干渉、穢れ図鑑。
- 仲間の一度限りの個別イベント、基地レベルに応じた外観モジュール。
- N/R/SR/SSR/URのゲーム内通貨ガチャ。キャラクターのレアリティ・特性・育成上限の共鳴強化、全100種類の武器獲得・所持武器の装備切替・強化。武器は大剣・重量武器、剣、双剣、槍、銃器の5系統に分類。
- 通常攻撃F、エネルギーを消費する強攻撃Shift+F、戦闘中のみ表示される必殺技ゲージと必殺技G。武器の扱いやすさに応じて、攻撃しにくい武器は22回、標準武器は33回、攻撃しやすい武器は46回の攻撃で必殺技が使用可能。戦闘終了時にゲージはリセットされる。
- 任務ログ、第1章の大型穢れ「時喰らい」との決戦、3種類の結末記録。研究・捕獲・解析の進行でボスが解放される。
- セーブ形式v16。旧形式v2〜v15の読み込み、20分ごとの自動保存、クイック手動保存、3つの保存スロット、2世代バックアップと復旧。

## 開発段階・未完成項目
この開発ビルドは第1章の進行基盤です。まだ完成版ではありません。広大なシームレスマップ、仲間30人全員の固有モデル・イベント、本格的なモーションキャプチャ品質のアニメーション、フルボイス・楽曲・高度な環境音、車両の物理シミュレーション、複数章のストーリー、より複雑なNPC記憶喪失・関係変化、セーブスロット、外部LLM接続は引き続き開発対象です。今回の検証はソース構文と機能配置の確認であり、ブラウザ上の実プレイ検証は未実施です。

## 主要方針
- 舞台：惑星APURF789
- 主人公：戦争当時12歳、施設内で8年を過ごして20歳で覚醒。外界では数億年経過。
- 開始時：主人公と内部AI N.O.V.A.のみ。加入可能仲間は約30人だが、開始時点では誰も加入していない。
- 全モンスターは「穢れ」。穢れからの記憶抽出は通常の2倍の記憶侵食ペナルティ。
- 記憶の貸借・奪取はNPCの状態や関係に影響する。
- PCはキーボード操作、スマートフォン・タブレットはタッチ操作に対応。
