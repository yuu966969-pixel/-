# RE:MEMORY — 忘却の時間

PC専用・キーボード操作のみの3D SF RPGプロトタイプです。

## 起動方法
- 会話機能は現在ローカルのルールベース応答です。プレイヤーの入力や会話履歴を外部サーバーへ送信しません。
- Three.js は jsDelivr CDN から読み込むため、初回起動時はインターネット接続が必要です。

- ローカル保存はブラウザの localStorage を使用します。

## 操作
| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| 視点 | ↑ / ↓ / ← / → |
| 調べる・観察・端末の研究画面を開く | E |
| 攻撃 | F |
| 穢れの捕獲 | C |
| ダッシュ | Shift |
| 局所時間操作 | Q |
| メニュー・設定 / データ管理 | Tab |
| メニュー内の選択移動 | ↑ / ↓ |
| 決定・開始・手動セーブ実行 | Enter |
| 戻る | Esc |

研究画面の選択も ↑ / ↓ と Enter で操作します。手動セーブは Tab で開くシステムメニュー内の「設定 / データ管理」から実行します。追加の番号キーや専用ショートカットは使いません。

マウス操作・タッチ操作は実装対象外です。

## 10項目の実装状況（プレイ可能な初期システム）
1. **3D世界・主人公移動** — Three.js 三人称視点、WASD移動、矢印視点、Shiftダッシュ。回収用ローバーへの乗降・運転もEと同じ移動キーで操作。
2. **APURF789荒廃世界** — 崩壊施設、瓦礫、廃墟、時間異常の雰囲気を持つ探索ステージ。
3. **クロノス計画ストーリー** — 惑星史、計画の兵器転用、核戦争、主人公の8年間と外界の数億年を記録アーカイブに収録。
4. **N.O.V.A.・NPC自由入力会話** — N.O.V.A.、商人、仲間に自由文で質問。現状はゲーム内知識に基づくローカル応答で、入力は外部送信されません。会話履歴はセーブデータに保存。外部LLM連携は未実装。
5. **穢れ戦闘・捕獲** — 穢れの接近、耐久、攻撃による弱体化、捕獲ビーコン。
6. **穢れ研究施設** — 収容室・観察室・記憶解析室・能力実験室・耐性研究室・資料庫を個別に修復する段階進行。捕獲個体と資材が必要。
7. **記憶システム** — 記憶のエネルギー変換と侵食、仲間への貸出、仲間からの一時借用、返却操作。貸出中は主人公がその記憶を使えない。
8. **仲間・編成・育成** — 外界で生存者と遭遇してから仲間を登録。主人公は固定枠。仲間の編成切替と資材による育成。
9. **基地運営** — 旧観測拠点の確保、壁・屋根・端末を備えた拠点内装、司令室・医療・記憶保管・研究設備の段階拡張。
10. **ガチャ・装備** — N/R/SR/SSR/URの確率を表示するゲーム内通貨限定抽選。仲間の共鳴強化、装備抽選、重複補償、装備強化。

- 20分ごとの自動保存、重要イベント時の即時保存、手動セーブ、2世代バックアップと復旧処理。セーブ形式はv6で、旧形式v2〜v5も読み込みます。
- 進行データにはレベル、経験値、基地、仲間、編成、記憶貸借、N.O.V.A.成長、装備、通貨、ストーリー進行、相手別の会話履歴を含みます。

## 会話機能の現状
- 現在はゲーム内の知識データとNPCごとの応答ルールで返答します。
- 会話内容はブラウザ内で処理し、外部APIへ送信しません。
- 本物の外部LLMを接続する場合は、サーバー側の認証・個人情報保護・利用上限を整備してから別途実装します。ブラウザ側へAPIキーを置きません。

## 今回の追加実装
- N.O.V.A.・NPC会話をローカル応答へ変更。未設定の `/api/chat` に依存せず、入力文を外部へ送信しない。
- ガチャにN/R/SR/SSR/URの抽選率（50/30/14/5/1%）を表示し、重複時の共鳴・素材補償を実装。
- 穢れ研究施設を6室の個別修復進行へ変更。
- 基地の司令室・武器工房・医療室・記憶保管庫・N.O.V.A.解析室の段階開放を実装。
- 記憶貸借にゲーム内時間10分の返却目安を追加。期限超過時は信頼が低下するが、返却は可能。
- ローバーと主人公の移動範囲・主要施設周辺の簡易衝突制限を追加。
- ミナの会話中の口の動きと、口が開いている時だけ見える歯の簡易表示を追加。
- フィールドでレン・ユイと遭遇できるようにし、実際に発見した人物だけ仲間リストへ追加。
- 「残響喰らい」「時層漂流体」の2種を追加。既存個体と合わせて複数の穢れを観察・弱体化・捕獲でき、個体別のHP・捕獲状態を保存。討伐報酬の重複取得も防止。
- 3か所に記憶結晶を配置。回収すると固有の記憶・経験値・資材を取得し、回収状況をセーブ。
- セーブ形式v6へ更新し、研究室・ゲーム内経過時間・記憶貸借期限を保存。

## 開発方針
- 舞台：惑星 APURF789
- 開始時：主人公（20歳）と内部AI N.O.V.A.のみ。仲間は初期施設にいない。
- 戦争当時12歳。本人にとって8年後に覚醒したが、外界では数億年が経過。
- モンスターはすべて「穢れ」に分類。
- 穢れの記憶抽出は通常の2倍の記憶侵食ペナルティ。
- キーボードのみ。マウス・タッチ操作なし。
