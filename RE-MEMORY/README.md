# RE:MEMORY — 忘却の時間

PC専用・キーボード操作のみの3D SF RPGプロトタイプです。

## 起動方法
- `RE-MEMORY/index.html` をWebサーバー経由で開いてください。
- Three.js は jsDelivr CDN から読み込むため、初回起動時はインターネット接続が必要です。
- ローカル保存はブラウザの localStorage を使用します。

## 操作
| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| 視点 | ↑ / ↓ / ← / → |
| 調べる・観察・端末の研究画面を開く | E |
| 攻撃 | F |
| 穢れの捕獲 | C |
| ダッシュ | Shift |
| 局所時間操作 | Q |
| メニュー・設定 / データ管理 | Tab |
| メニュー内の選択移動 | ↑ / ↓ |
| 決定・開始・手動セーブ実行 | Enter |
| 戻る | Esc |

研究画面の選択も ↑ / ↓ と Enter で操作します。手動セーブは Tab で開くシステムメニュー内の「設定 / データ管理」から実行します。追加の番号キーや専用ショートカットは使いません。

マウス操作・タッチ操作は実装対象外です。

## 10項目の実装状況（プレイ可能な初期システム）
1. **3D世界・主人公移動** — Three.js 三人称視点、WASD移動、矢印視点、Shiftダッシュ。回収用ローバーへの乗降・運転もEと同じ移動キーで操作。
2. **APURF789荒廃世界** — 崩壊施設、瓦礫、廃墟、時間異常の雰囲気を持つ探索ステージ。
3. **クロノス計画ストーリー** — 惑星史、計画の兵器転用、核戦争、主人公の8年間と外界の数億年を記録アーカイブに収録。
4. **自由入力会話** — N.O.V.A.、商人3人、仲間ミナに自由な文章で話しかけられる会話画面。相手ごとの知識・口調・反応、会話履歴の保存に対応。現在の返答はゲーム内のルールベース方式で、外部AI/APIによる無制限な文章生成ではありません。
5. **穢れ戦闘・捕獲** — 穢れの接近、耐久、攻撃による弱体化、捕獲ビーコン。
6. **穢れ研究施設** — 収容・観察・記憶解析・能力実験・耐性研究・資料庫を段階強化する管理画面。捕獲個体と資材が必要。
7. **記憶システム** — 記憶のエネルギー変換と侵食、仲間への貸出、仲間からの一時借用、返却操作。貸出中は主人公がその記憶を使えない。
8. **仲間・編成・育成** — 外界で生存者と遭遇してから仲間を登録。主人公は固定枠。仲間の編成切替と資材による育成。
9. **基地運営** — 旧観測拠点の確保、壁・屋根・端末を備えた拠点内装、司令室・医療・記憶保管・研究設備の段階拡張。
10. **ガチャ・装備** — ゲーム内クレジットのみのキャラクター候補スカウト・装備抽選、重複補償、装備強化。

- 20分ごとの自動保存、重要イベント時の即時保存、手動セーブ、2世代バックアップと復旧処理。
- 進行データにはレベル、経験値、基地、仲間、編成、記憶貸借、N.O.V.A.成長、装備、通貨、ストーリー進行、相手別の会話履歴を含みます。

## 直近の修正・動作上の注意
- メニューの重複定義を解消し、全システムのメニュー項目から各画面へ移動できるよう修正。
- N.O.V.A.・商人・仲間の自由入力会話を追加。会話中は矢印キーで入力カーソルを動かせ、Enterで送信。会話履歴はセーブデータに保存。
- 返答は現段階ではキャラクター別の知識とキーワード判定によるローカル方式。外部AI連携はAPIキーを安全に保管するサーバーが必要なため未導入。
- オーバーレイをキーボードフォーカス可能に修正。ゲーム開始もEnterで実行。
- 回収用ローバーを追加。Eで乗降し、WASDで走行。車両位置・向きもセーブ。

## 開発方針
- 舞台：惑星 APURF789
- 開始時：主人公（20歳）と内部AI N.O.V.A.のみ。仲間は初期施設にいない。
- 戦争当時12歳。本人にとって8年後に覚醒したが、外界では数億年が経過。
- モンスターはすべて「穢れ」に分類。
- 穢れの記憶抽出は通常の2倍の記憶侵食ペナルティ。
- キーボードのみ。マウス・タッチ操作なし。
