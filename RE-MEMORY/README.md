PC専用・キーボード操作のみの3D SF RPGプロトタイプです。

## 起動方法
- オンラインAI版は `RE-MEMORY/render.yaml` を使ってRenderへデプロイし、Cloudflare Workers AIの接続情報をサーバー環境変数に設定します。詳しくは `server/README.md` を参照。
- 無料枠には日次上限があり、無制限ではありません。
- ローカルで試す場合はOllamaも利用できます。
- Three.js は jsDelivr CDN から読み込むため、初回起動時はインターネット接続が必要です。
- ローカル保存はブラウザの localStorage を使用します。

## 操作
| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| 視点・メニュー移動 | 矢印キー |
| 調べる・会話・端末 | E |
| 攻撃 | F |
| 穢れの捕獲 | C |
| ダッシュ | Shift |
| 時間操作 | Q |
| メニュー・設定 / データ管理 | Tab |
| 決定・開始・手動セーブ実行 | Enter |
| 戻る | Esc |

マウス操作・タッチ操作は実装対象外です。

## AIサーバー
オンライン版はCloudflare Workers AIをゲームサーバー経由で利用します。無料枠には日次上限があり、Render Freeは一定時間アクセスがないと休止する場合があります。APIトークンはサーバー環境変数だけに保存し、GitHubやブラウザへ公開しません。ローカルAIの手順は `server/README.md` を参照。

## 開発段階
本リポジトリは開発中のプロトタイプです。設計資料に記載された機能、ストーリー、仲間30人、分岐エンディングが全て実装済みという意味ではありません。企画仕様と実装状況を区別し、機能追加後は動作確認を行ってください。

## 主要方針
- 舞台：惑星APURF789
- 主人公：戦争当時12歳、施設内で8年を過ごして20歳で覚醒。外界では数億年経過。
- 開始時：主人公と内部AI N.O.V.A.のみ。加入可能仲間は約30人だが、開始時点では誰も加入していない。
- 全モンスターは「穢れ」。穢れからの記憶抽出は通常の2倍の記憶侵食ペナルティ。
- 記憶の貸借・奪取はNPCの状態や関係に影響する。
- キーボード専用。マウス・タッチ操作なし。
