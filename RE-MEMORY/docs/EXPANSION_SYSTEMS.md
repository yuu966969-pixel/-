# RE:MEMORY — 拡張システム仕様

## v13で実装したプロトタイプ機能
- 武器100種類に視覚スタイル、固有エフェクト名、パッシブ説明、バリエーションIDを追加。
- 大剣・剣・双剣・槍・銃器のカテゴリ別3Dモデル。通常・強攻撃・必殺技で右腕と武器リグの振りモーションを変更。銃器は最大18mの射撃弾、槍は最大6.5mの攻撃距離を持つ。
- 武器ごとの強化値とレアリティ補正を装備切替後も維持。
- 武器モジュール5種：時相刃（威力+12%）、残響コア（威力+8%）、穢れ解析レンズ（威力+15%）、安定化フレーム（攻撃間隔-8%）、記憶プリズム（必殺技ゲージ蓄積補助）。各武器最大3枠。
- 防具6種。防御値・耐性の表示、購入・装備切替、3D外観。防御値はパーティー防御計算へ反映し、時間異常・近接衝撃・記憶侵食への耐性は対応する被害を軽減。
- 探索マップ：施設・拠点・時間異常区域3か所。接近による自動発見、座標、解析状況を表示。
- 時間異常区域3か所：西部・逆流裂け目、東部・停滞回廊、北部・記憶降雨域。Eキーでエネルギー8を消費して解析し、資材・クレジット・経験値・N.O.V.A.成長を獲得。区域内では移動速度が低下。
- 穢れ図鑑：施設外縁型、残響喰らい、時層漂流体、時喰らい。観察した個体だけ詳細を開示し、捕獲記録を表示。
- 仲間個別イベント：仲間ごとに一度だけ発生。記憶共有または傾聴を選び、信頼と記録へ反映。
- 基地レベル2〜5で外観モジュールが段階的に表示される。
- セーブ形式v13。v2〜v12の既存データを読み込み、新規項目は初期値で補完。

## 操作
- Tab：メニューから探索マップ、穢れ図鑑、武器工房・防具研究を開く。
- 武器・防具・改造・仲間イベントはメニュー内の矢印キーとEnterで操作可能。
- E：時間異常区域の解析。

## 制約
- 武器はカテゴリ別の手続き生成モデルであり、100種類すべてが完全に異なる専用3Dアセットではない。
- 防具は装備ごとの色・プレート構成を反映した簡易モデル。
- アニメーションは手続き的な右腕・武器リグの振り動作で、モーションキャプチャ品質ではない。
- マップは座標・地点リスト型。2D地形表示や経路探索は未実装。
- 仲間イベントは選択式の短いプロトタイプで、全員分の完全な専用クエストではない。
- 時間異常区域は3か所の試作コンテンツで、大規模なシームレス世界や複雑な環境ギミックは今後の拡張対象。
- ブラウザ上の実プレイ検証は未実施。ソース検査・JSON検査を実施してから利用すること。
